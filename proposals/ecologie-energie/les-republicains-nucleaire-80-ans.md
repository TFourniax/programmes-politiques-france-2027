# Inscrire le parc nucléaire dans une trajectoire de 80 ans

Le parti propose une trajectoire permettant d'exploiter le parc nucléaire jusqu'à 80 ans lorsque les conditions de sûreté et les décisions de l'autorité compétente le permettent.
