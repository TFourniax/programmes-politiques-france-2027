# Établir en cent jours un nouveau code de procédure pénale

La convention régalienne de Renaissance propose de créer une commission réunissant magistrats, professionnels du droit, universitaires et représentants des forces de l'ordre afin d'établir en cent jours un nouveau code de procédure pénale, avec l'objectif d'un droit plus clair et de procédures plus rapides.
