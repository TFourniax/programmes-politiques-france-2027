# Politique des sources

## Niveaux de sources

### Niveau 1 — Source primaire officielle

Exemples : Conseil constitutionnel, ministère de l’Intérieur, CNCCEP, Journal officiel, site officiel d’un candidat, site officiel d’un parti, communiqué officiel, PDF de campagne, chaîne ou compte officiel vérifié.

### Niveau 2 — Source primaire médiatique

Exemples : entretien intégral, débat complet, discours retransmis, conférence de presse disponible en intégralité.

### Niveau 3 — Source secondaire fiable

Exemples : AFP, Le Monde, Franceinfo, Radio France, LCP, Public Sénat, Reuters, presse nationale ou régionale reconnue, organismes de fact-checking.

### Niveau 4 — Source exploratoire

Exemples : Wikipédia, blogs, agrégateurs, forums, comptes non officiels ou sites de soutien non reconnus.

## Règles

- Une source primaire disponible doit toujours être privilégiée.
- Une source secondaire ne remplace pas une source primaire lorsqu’elle existe.
- Une source exploratoire ne peut pas suffire à valider une candidature, un programme ou une proposition.
- Chaque information substantielle doit être datée.
- Chaque changement de statut doit conserver son ancienne valeur dans l’historique.
- Les sources ambiguës ou disparues doivent être signalées dans `research/missing-information.md`.
