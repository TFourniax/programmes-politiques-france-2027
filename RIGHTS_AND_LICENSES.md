# Droits et licences

## Principe

Un document public n’est pas nécessairement librement reproductible. Le dépôt distingue donc :

- le code du projet ;
- les métadonnées produites par le projet ;
- les textes politiques originaux appartenant à leurs auteurs ou éditeurs.

## Statuts de droits

Les valeurs autorisées sont :

- `open_license` ;
- `public_domain` ;
- `permission_granted` ;
- `quotation_only` ;
- `link_only` ;
- `unknown` ;
- `restricted`.

## Règles

- En cas de doute, ne pas reproduire le texte complet.
- Utiliser `link_only` ou `unknown` tant que les droits ne sont pas établis.
- Les livres, articles de presse, professions de foi restreintes et transcriptions non autorisées ne doivent pas être recopiés intégralement.
- Les courtes citations doivent rester strictement nécessaires à la vérification.
- Les métadonnées, résumés originaux et liens vers sources sont privilégiés.

## Registre

Chaque document sensible doit être référencé dans `registries/rights.yaml` avec titulaire des droits, preuve, date de consultation et actions autorisées.
